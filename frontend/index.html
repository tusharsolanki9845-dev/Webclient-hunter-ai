How It Works

A Four-Step Workflow

Use the workflow to prepare client-research material, and independently verify each finding before making contact.

1

Search & Discover

Enter a niche and location to create a list of businesses for research.

2

Review Website Signals

Run an available website check and review the reported SEO, speed, mobile, and security signals.

3

Prepare Outreach

Create an editable draft based on the findings, then verify the details and tailor it before use.

4

Organise Follow-Up

Record research notes and follow-up status in the workspace.
